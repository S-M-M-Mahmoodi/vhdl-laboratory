Structural VHDL Architecture & Modular Hierarchy

        
In digital logic and computer architecture engineering, complex hierarchical circuits (such as multi-bit adders, ALUs, and datapaths) are constructed by interconnecting reusable sub-blocks:

        
    
          
  1. Modular Design: Create primitive blocks (e.g., half_adder.vhd, full_adder.vhd) first using the Project Navigator (+).
    2. 
          
  2. Component Declaration: In your parent module's architecture declarative region (before begin), declare the component signature:
            
    component half_adder is
  port (
    a, b : in  std_logic;
    sum, carry : out std_logic
  );
end component half_adder;
    
          
    3. 
          
  3. Component Instantiation with Port Map: Inside the architecture body (after begin), instantiate instances connected via internal signals:
            
    HA1: half_adder
  port map (
    a     => in_a,
    b     => in_b,
    sum   => s1,
    carry => c1
  );
    
          
    4. 
          
  4. One-Click Snippet Helpers: Right-click any file in the Project Navigator to immediately copy its Component Declaration or Port Map Instantiation directly to your clipboard.
    5. 
          
  5. Automatic Multi-File Analysis: GHDL compiles all design sources in the project together, resolving structural bindings automatically at elaboration time.
    6. 
        

      


      
      

        
Advanced Waveform Analysis & Timing Verification

        
    
          
  • Zero Negative Time: The simulation timeline is strictly positive ($t \ge 0\text{ ns}$), eliminating negative time scroll artifacts.
    • 
          
  • Dual Measurement Cursors: Left-click sets Cursor A; right-click or Shift+click sets Cursor B. The time delta ($\Delta t$) and frequency ($f = 1/\Delta t$) update in real-time in the status bar.
    • 
          
  • Real-Time Value Inspector: Active signal values at the cursor position are displayed directly in the left signal label column in your choice of Hex, Decimal, or Binary.
    • 
          
  • Clock Edge Snapping (|◀ and ▶|): Jump buttons snap the cursor directly to the previous or next signal transition for rapid timing margin measurements.
    • 
          
  • Zebra Striping: Alternating row shades ensure effortless visual tracking across dense signal lists.
    • 
          
  • High-Resolution SVG & PNG Export: Dedicated margin separation prevents signal names and waveform traces from ever overlapping in exports.

Preventing VHDL Integer Range Failures:

        
VHDL integer ranges (such as range 0 to 15) do not automatically wrap around. To avoid a bound check failure during simulation, always include an explicit reset condition: if count >= 15 then count <= 0; else count <= count + 1; end if;
